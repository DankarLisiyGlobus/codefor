# codeFor - Форум для программистов

Полнофункциональный форум для сообщества программистов на Python/Flask.

## Установка и запуск

1. Установите зависимости: pip install -r requirements.txt

2. Запустите приложение: python app.py

3. Откройте в браузере: http://127.0.0.1:5000

## Данные админа по умолчанию:
- Логин: admin
- Пароль: admin123

## Функционал:

### Для всех пользователей:
- Регистрация и авторизация
- Создание постов с HTML форматированием
- Просмотр ленты постов с пагинацией (20 постов на страницу)
- Прикрепление файлов и изображений к постам
- Изображения встраиваются в пост (base64)
- Профили пользователей с GitHub ссылкой
- Светлая/темная тема
- Мультиязычность (RU/EN) с возможностью добавления новых языков

### Для администраторов:
- Панель управления пользователями
- Бан/разбан пользователей (помечаются, не удаляются из БД)
- Удаление/восстановление пользователей
- Удаление любых постов (помечаются, сохраняются в БД)
- Просмотр удаленных постов
- Восстановление удаленных постов
- Забаненные пользователи видны, но их посты скрыты
- Удаленные пользователи видны только админам

## Технологии:
- Backend: Python 3.x, Flask, SQLAlchemy
- Database: SQLite
- Frontend: HTML5, CSS3, JavaScript
- Templates: Jinja2
